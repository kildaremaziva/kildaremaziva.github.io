SQL ServerExcel

Data exploration in SQL and Excel

I used SQL Server to explore Horizon Financial Group’s loan data. Then I used Excel to run correlation analysis and build a dashboard, to find what is linked to loan defaults.

  • 146 of 601 loans defaulted: 24.3%, double the 12% target.
  • Defaults were highest for credit scores of 520–599 (about 49%) and lowest above 750 (about 11%).
  • Higher yearly income meant fewer defaults.
